# Space Rocks

Space does rock. This game is about dodging space rocks using directional keys or dragging the mouse. 

## Project

Created as final project for SER120 - Object-oriented programming, this game had to meet certain criteria to demonstrate
learning that occurred over the semester. I also had a bit of fun with it.
